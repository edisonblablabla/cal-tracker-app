# NutriPulse - Modern Health & Fitness Web Application

NutriPulse is a responsive, feature-rich health, nutrition, and social fitness tracking web application built with React, Vite, Tailwind CSS / Custom UI, and Firebase backend services.

## 🚀 Key Features

### 1. Home Dashboard
* **Today Overview**: Real-time Progress Ring tracking daily calorie targets and Macronutrients (Protein, Carbs, Fats).
* **Rest / Workout Day Modes**: Dynamic target auto-adjustments (+200 kcal on workout days).
* **GPS Step & Distance Tracker**: Browser geolocation tracking for walk distance and active burn calculations.
* **Workout Countdown Timer**: Activity selection with live timer and estimated calorie burn logging.

### 2. Nutrition Log
* **Custom Meal Logging**: Record food dish name, portion size, calories, and macros.
* **Meals History**: Reverse-chronological daily food log with quick "Last Meal" highlight badge and instant deletion.

### 3. Social Tab (NutriPulse Feed)
* **Branded Interface**: Sleek, mobile-first feed layout inspired by modern social networks.
* **Athlete Search & Notifications**: Private-by-default overlay search and notification sheet for pending Booster requests.
* **Multi-Level Post Privacy**: Public, Boosters Only, and Private options.
* **Pulses & Resonate**: Heart reaction counters and post-sharing bottom sheet.

### 4. Progress & Health Status
* **5-Entry Weight Trend**: Dynamic bar chart mapping recent body weight logs.
* **BMI & Hydration Tracker**: Automatic Body Mass Index classification score bar and daily water intake recommendation.

### 5. Athletic Profile
* **Ultra-Compact Design**: Streamlined layout prioritizing post creation visibility.
* **Direct Media Uploads**: Camera buttons on Avatar and Cover photo for instant profile picture changes.
* **Real-time Stats Grid**: Counts for Boosting, Boosters (interactive popup lists), Streak, and total Pulses received.

### 6. Admin Panel (Moderation Vault)
* **Evidence Vault**: Non-destructive moderation allowing post hiding and user account restriction while preserving records.
* **Presence Monitor**: Real-time 30-second heartbeat tracking for active user accounts.

---

## 🛠️ Technical Stack
* **Frontend**: React (JSX), Vite, JavaScript (ES6+), Custom UI
* **Backend / Database**: Firebase Authentication, Firestore Cloud Database
* **Deployment**: GitHub Pages (`gh-pages`)
